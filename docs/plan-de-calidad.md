# Plan de Calidad: resumen

El documento completo se entrega en PDF (Etapa I). Resumen de los puntos que se verifican en el repositorio:

- **Requerimientos:** [requerimientos.md](requerimientos.md) (RF-01 a RF-11, RNF-01 a RNF-07).
- **Historias de usuario y backlog:** [historias-de-usuario.md](historias-de-usuario.md), [backlog.md](backlog.md).
- **Diagramas:** [diagramas/](diagramas/), casos de uso, modelo de base de datos y flujo para agendar.
- **Control de cambios:** [../CONTRIBUTING.md](../CONTRIBUTING.md) y [bitacora-cambios.md](bitacora-cambios.md).
- **Metodología:** Scrum adaptado a una integrante, sprints de 2 semanas, tablero Kanban en GitHub Projects.

## Métricas de calidad

| Métrica | Meta |
|---|---|
| Requerimientos funcionales implementados y aprobados | 100 % al cierre |
| Casos de prueba aprobados | ≥ 90 % |
| Defectos críticos abiertos al entregar | 0 |
| Tiempo promedio para agendar una asesoría | ≤ 2 min |
| Lighthouse - Rendimiento | ≥ 85 |
| Lighthouse - Accesibilidad | ≥ 90 |
| Satisfacción de usuarios (SUS) | ≥ 70 |
| Historias completadas por sprint | ≥ 80 % |
| Desviación del cronograma | ≤ 10 % |
| Reservas empalmadas | 0 |
